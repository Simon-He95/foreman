# Recipe: research

Use the master for a fresh investigation, not a stale report.

```text
调研 <library> 最近的下载和社区热度，输出一份独立报告，
包含 npm 周下载、GitHub 指标、版本分布和结论。
```

What happens:

- leader chooses a `deep` task, `strong + max` by default
- ACP agent creates a native child thread
- worker uses its network/web tools
- report path is verified if an artifact contract is configured
- completion notification includes the child thread link

Tip: ask for a fresh report explicitly if an old one exists. “Latest report”
means “show me the old result”; “re-run research” means “create a new task”.
